Image Bench

22 tools for getting a photo exactly the way you need it.

From a quick compress before you email a photo, to a precise pixel resize for a web upload, to stamping a batch of images with a watermark the Image Bench is a full editing bench for JPG, PNG and WebP files. Every tool runs on the Canvas API already built into your browser, so nothing ever leaves your tab.
