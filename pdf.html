PDF Tools Guide

How to use the Merge PDF tool

Combining multiple documents into a single cohesive file is a frequent requirement for legal professionals, educators, and office workers. This tool seamlessly stitches together your PDFs right inside your browser without any round-trips to a server. You can quickly consolidate monthly reports or assemble a complete portfolio securely.

Step-by-step instructions:

  1. Drag and drop your PDF documents into the upload area.
  2. Reorder the files if necessary to match your desired output sequence.
  3. Click the 'Merge' button to bind them together.
  4. Save the newly created single PDF file to your local drive.

Frequently Asked Questions

Will my documents be uploaded?

No, the merging process utilizes PDF-lib locally in your browser. Nothing is ever transferred over the internet.

Can I merge files of different sizes?

Absolutely, files with varying dimensions and layouts can be merged effortlessly without losing formatting.

Pro Tip: To prevent layout issues, ensure that the page orientations (portrait vs landscape) match where possible, though the tool handles mixed orientations without dropping content.

How to use the Split PDF tool

When you have a massive PDF but only need a few specific pages, breaking it apart is the most efficient solution. The Split PDF feature slices your bulky documents into individual, manageable pages locally. It is perfect for extracting invoices from a bulk batch or sharing a single book chapter.

Step-by-step instructions:

  1. Select the PDF you want to break apart.
  2. Specify if you want all pages split or a particular subset.
  3. Initiate the split operation.
  4. Download your individual pages packed neatly in a ZIP archive.

Frequently Asked Questions

How are the output files named?

Each page is saved with a sequential suffix corresponding to its original page number.

Is there a limit on how many pages I can split?

Since processing happens entirely client-side using PDF-lib, your device's memory is the only practical limitation.

Pro Tip: For extremely large files (500+ pages), ensure your browser has enough RAM available, as the extraction happens locally.

How to use the Rotate PDF tool

Scanned documents often come out upside down or sideways, making them frustrating to read. By rotating your PDF pages, you can permanently fix orientation issues in seconds. This utility lets you correct the angle of every page uniformly without degrading the document quality.

Step-by-step instructions:

  1. Load the PDF containing the incorrectly oriented pages.
  2. Select the rotation angle: 90 degrees, 180 degrees, or 270 degrees.
  3. Apply the rotation transformation.
  4. Export the corrected file directly to your system.

Frequently Asked Questions

Does rotating the PDF reduce text clarity?

Not at all. The rotation modifies the document's metadata matrix via PDF-lib, keeping the original content completely intact.

Can I rotate just one page?

Currently, this tool applies the selected rotation to all pages globally for consistency.

Pro Tip: If only some pages are sideways, you might want to use the Extract Pages tool first, rotate them, and then Merge them back.

How to use the Compress PDF tool

Large PDF files often bounce back from email servers and consume too much storage space. Our local compression engine re-encodes image-heavy pages, reducing the overall file size dramatically. This is an essential utility for sharing scanned documents, portfolios, or graphic-heavy presentations.

Step-by-step instructions:

  1. Upload your large PDF document into the tool.
  2. Choose a compression level balancing quality and file size.
  3. Start the optimization process.
  4. Review the file size savings and download the lighter PDF.

Frequently Asked Questions

How does the tool shrink the file?

It uses the HTML5 Canvas API to rasterize and re-encode high-resolution images at a more efficient DPI, leaving vector text untouched where possible.

Will my text become blurry?

Vector text remains perfectly crisp. Only embedded images and raster graphics are affected by the compression algorithms.

Pro Tip: For text-only PDFs, compression may not significantly reduce the size. This tool is most effective on documents containing many scanned pages or photos.

How to use the PDF to JPG tool

Converting PDF pages into individual JPG images is incredibly useful when you need to embed document snippets into presentations or upload them to social media. This entirely local process rasterizes your PDF content into standard image formats quickly. It turns multi-page reports into a simple gallery of images.

Step-by-step instructions:

  1. Import the PDF you wish to convert.
  2. Adjust any desired image quality settings.
  3. Click convert to rasterize the document.
  4. Download the resulting JPGs, which are bundled into a convenient ZIP file.

Frequently Asked Questions

What resolution are the JPGs saved at?

We use PDF.js to render the pages at a high scale factor, resulting in crisp images suitable for printing or screen viewing.

Is my sensitive data sent to an image server?

No, the entire rasterization process happens in your browser using the local Canvas API.

Pro Tip: If you need images with transparent backgrounds, try the PDF to PNG tool instead, as JPG does not support transparency.

Pro Tip: Optimize your images before converting if you want to keep the final PDF file size small. Alternatively, you can use the Compress PDF tool afterwards.

How to use the PDF OCR tool

By running your file through our local Optical Character Recognition (OCR) engine, you can extract the text from the images. Tesseract.js handles the heavy lifting entirely via WebAssembly in your browser.

Step-by-step instructions:

  1. Upload the scanned PDF document.
  2. Select the language of the text for better accuracy.
  3. Start the OCR process (this may take a moment depending on page count).
  4. Download the extracted text or a searchable PDF.

Why does OCR take longer than other tools?

OCR requires complex machine learning models to visually analyze every pixel on the page locally via Tesseract.js.

Does it work on handwritten notes?

Accuracy is significantly lower for handwriting. It works best on standard printed typography.

Pro Tip: For faster processing, only run OCR on the specific pages you need by using the Extract Pages tool first.
